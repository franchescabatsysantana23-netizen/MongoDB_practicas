--> creacion de un indice de tipo text

db.ventas.createIndex({estado:'text'})

--> consulta para visualizar la descripcion con explain

db.ventas.find({$text:{$search:'completada'}}) -retorna todos los documentos con el estado completada. 
db.ventas.find({$text:{$search:'completada'}}).explain("executionStats")

stage: 'TEXT_MATCH' --> muestra que esta usando el indice de tipo text. 

--> creacion de un indice de tipo hash index  

 db.ventas.createIndex({total:'hashed'})

consulta para visualizar la descripcion con explain, 

db.ventas.find({total:650}).explain("executionStats")

-->para verificar que la consulta usa el indice stage: 'IXSCAN'

nota: MongoDB no permite índices hashed sobre campos que contienen arrays.
Un índice hashed en MongoDB no cambia cómo escribes la consulta; lo que cambia es cómo MongoDB busca internamente. Estos índices solo sirven para igualdad (=), no para rangos ($gt, $lt, etc.).

ejemplos: 
db.pedidos.createIndex({ usuarioId: 1, fecha: -1 })
ideal para consulta como: 
  db.pedidos.find({ usuarioId: 123 }).sort({ fecha: -1 })
